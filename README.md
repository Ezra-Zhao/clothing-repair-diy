# 衣服维修与自制

衣服破了先别扔。这一仓是一套中文的衣服维修与自制实操手册：补洞、缝开线、换拉链、钉扣子、改尺寸，一直到用开源工具给自己打版做衣服，全部写成照着就能做的步骤。

定位：文明重启文库「生活层」基础技能之一。市面上的中文资料要么是带货短视频，要么散在论坛帖子里不成体系，这里把一门手艺按顺序整理成册，断网、离线也能照着干。

作者：Guangyi Zhao

## 怎么用这一仓

- 每章解决一类问题，章节之间不依赖，遇到哪类破损直接翻哪章。
- 步骤写到操作级：用什么针、什么线、先扎哪儿、再往哪儿走，都写明。带「[图：…]」标记的是配图占位，图补齐之前先看文字。
- 章首标「初稿待实操验证」的，表示文字稿已成但还没人照着完整做过一遍；实际做过验证的篇目会去掉这个标记。照做时发现对不上的地方，欢迎开 issue 报回来。

## 先修后买的判断顺序

1. 破损在受力小的位置（衣摆、袖口内侧）、面料本身还结实：自己补，半小时的事。
2. 破损在受力区（裤裆、膝盖、袜跟）但面料没整体磨薄：能补，要垫布加固，不能只缝表面。
3. 整片面料已经磨薄、发脆，或者洞大到补丁盖不住原有版型：这件降级成抹布或补丁布来源，别硬补。旧衣别整件扔，扣子、拉链、好布片都是后面章节的零件和材料。

## 基础工具清单

起步不用买齐，先备一个针线包就能干大半活：

- 手缝针一包（多号混装）：普通缝补用 Sharps（手缝针）；织补用针眼长的织补针（darning needle）；刺子绣用长针（约 5 厘米）。
- 线：棉线、涤纶线各几色（黑、白、藏青先行），牛仔线（粗线）一卷，毛线留同色余线。
- 织补菇（darning mushroom）：没有可用光滑的灯泡、圆底瓶子、光滑石头代替，作用是把破洞撑平。
- 剪刀一把小的（剪线头）、拆线刀一个、珠针一盒、划粉或水消笔一支。
- 熨斗：补前补后都要熨，定型和压平全靠它。
- 后面章节会用到的：缝纫机（换拉链、改尺寸时效率差很多）、顶针（推厚布必备）。

针号有个反直觉的规矩：同一类针里，号数越大针越细越短。买混装包时对照包装背面的号数表选，别凭手感猜。

## 资源索引

自己写步骤之外，这几个开源项目是真能用上的工具（2026-10-18 GitHub 实查，星数以当时为准）：

- FreeSewing — https://github.com/freesewing/freesewing （约 486 星）
  开源量身纸样平台，官网 freesewing.org 按个人尺寸免费生成衬衫、裤子、外套等纸样，打印后裁布缝制。第六章会带完整流程。
- Seamly2D — https://github.com/FashionFreedom/Seamly2D （约 1,001 星）
  开源打版软件，自己画纸样、改尺寸，做衣服和改衣服都用得上。
- Sewing_Tutorials — https://github.com/micgear/Sewing_Tutorials （约 91 星）
  免费缝纫教程，偏装备与户外服装缝制，针法与缝纫机基础讲得实。
- sashiko-pattern-library — https://github.com/Chillchamp1/sashiko-pattern-library
  刺子绣纹样小库，第一章补洞时想给补丁加纹样可以翻它。
